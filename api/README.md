# Memos API Contract

`openapi.yaml` is copied verbatim from the Memos `v0.30.0` tag:

```text
https://github.com/usememos/memos/blob/v0.30.0/proto/gen/openapi.yaml
commit 2036c1ffc1b0a1e1fa6a473738c2a5ef520df67f
```

`openapi.codegen.json` is generated by `tools/openapi-normalizer`, which also repairs the v0.30 instance-setting wildcard route emitted by `protoc-gen-openapi`. Run `scripts/update-api.sh` after intentionally replacing the pinned source contract. Do not update this file from Memos `main` without also changing the supported server version: post-v0.30 main currently contains API changes that are not available in the v0.30 release binary.
