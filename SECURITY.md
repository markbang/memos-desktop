# Security Policy

## Supported Versions

Only the latest release and the default branch receive security fixes.

## Reporting A Vulnerability

Please do not open a public issue for a suspected security vulnerability. Report it privately through [GitHub Security Advisories](https://github.com/markbang/memos-desktop/security/advisories/new).

Include:

- affected version or commit;
- platform and runtime details;
- reproduction steps or a minimal proof of concept;
- impact assessment, if known.

Do not include real Memos credentials, access tokens, private memo contents, or production URLs in a report.

We will acknowledge a report when triage begins and coordinate disclosure after a fix is available.
